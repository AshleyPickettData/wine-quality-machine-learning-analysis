# Wine Quality Prediction Through Machine Learning

## Project Overview
This project analyzes wine chemical composition data to predict wine quality using machine learning techniques. The goal was to reduce subjectivity in wine quality assessment by building automated predictive models based on measurable chemical properties.

## Business Problem
Traditional wine quality assessment relies heavily on expert tasters, making the process subjective, time-consuming, and difficult to scale. This project explores how machine learning can improve consistency and operational efficiency in wine quality evaluation.

## Key Insights
- Alcohol content showed the strongest positive relationship with high-quality wine
- Density displayed a strong negative correlation with alcohol content
- The dataset contained significant class imbalance, reflecting the rarity of premium-quality wines
- Random Forest and SVM achieved strong predictive performance for identifying high-quality wines

## Business Recommendations
- Implement automated quality screening to reduce reliance on expensive tasting panels
- Use clustering profiles for targeted customer segmentation and pricing strategies
- Integrate predictive models into real-time production monitoring systems
